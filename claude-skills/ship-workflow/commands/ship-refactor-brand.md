# Ship Refactor Brand

Read and follow [the brand workflow](../skills/ship-refactor-brand/SKILL.md),
including its referenced decision, evidence and Roadmap integration guidance.
Resolve those references relative to that skill directory in this installation.
Run against the user's target repo and pass the optional scope argument as scan scope.

Start with the brand-direction step: three rendered directions in one comparison mockup, then wait for the pick (or reuse the recorded one).

Produce the inventory, integration proposals and migration order in linked human
HTML and AI Markdown reports. Present the proposed rows for selection, then add
only the selected work to Next through ship's existing helpers. Implementation
belongs to `/ship-next`; this command does not execute the refactor.
